# Team Guidelines

## Team Workflow

Each member develops their own profile and related information on their assigned branch.

## Current Assignments

- JA: JA Portfolio
- HG: HG Portfolio

## Coding Standards

- Add meaningful comments.
- Use reusable components.
- Avoid hardcoding repeated content.
- Keep data in `src/data`.
- Keep styling organized by component/page.
- Test before pushing.
- Do not commit `node_modules`.
- Do not add sensitive private information.

## Pull Request Checklist

Before creating a PR:

- App runs without errors.
- Pages load correctly.
- No broken routes.
- No private information exposed.
- Code is commented where helpful.
- Branch is updated with `dev`.
